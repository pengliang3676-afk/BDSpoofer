10.01.12: 网页侧注入伪装系统版本（改 UA）

10.01.11 基准确认：网页读到的 UA 是
  Mozilla/5.0 (iPhone; CPU iPhone OS 16_7_2 like Mac OS X) ... (Baidu; P2 16.7.2)
而插件伪装的是 16.0 —— 网页这层漏了真机系统版本。

改动：
  ① 原生在 WKWebView 初始化时注入 window.__bdsWebSpoof={sv_under,sv_dot}
     值取自 bdspoofer_config.plist 的 systemVersion
  ② JS 改写 Navigator.prototype.userAgent / appVersion 的 getter：
       CPU iPhone OS x_y like  -> 伪装值
       (Baidu; P2 x.y)          -> 伪装值
  ③ 探测回报里加 o.spoof（当前伪装配置），便于对照

不改：screen.width/height、devicePixelRatio、innerWidth/Height
      （改屏幕尺寸有布局错乱风险，且 UA 里的系统版本才是主要破绽）
