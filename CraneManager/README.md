# 卍解 1.0.3 UI1

配套插件为卐解 1.8.2 UI1.2。三个随机按钮依次红、绿、蓝，设置入口统一为“反关联项”。定向一键随机会自动开启总开关和全部 5 个子开关，并生成整套定向参数；未执行时保持现有关闭状态。

容器列表加载时只读取现有配置，不创建缺失配置。配置通常在执行一键随机后写入；在“反关联项”页面手动改开关时，未生成配置的选中容器会以随包完整模板打底后写入，不会产生缺 configVersion 的残缺配置；未选中任何容器时，调整的是本机默认开关偏好并自动记住。已有的值及手动开关保留，每次写入均完整回读校验。

基础功能 7 项（含系统硬件参数）与高级前 2 项（百度身份参数、防越狱检测）默认开启，高级后 4 项默认关闭，与卐解共用同一套默认规则；出厂模板为 iPhone 17 Pro Max（iPhone18,2 / iOS 26.6 / 256GB）。已有配置的开关选择保留。

一键基础随机一次产出三层一致身份：基础参数抽到哪台机型，百度定向 5 组（系统/机型/屏幕/UA/Push）就同步为同一台机型并自动开启定向，同时开启 Keychain/AppGroup/Cookie/UA 四项残留隔离；蓝色定向随机与绿色高级身份随机仍可独立使用。

完整说明及验证边界见 [UI1 发布说明](../RELEASE_UI1.md)。
